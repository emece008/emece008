# Hola, soy Christian 👋

> **Filosofía:** Resolver problemas complejos sin sobreingeniería.

Muchos proyectos modernos acumulan cientos de dependencias pesadas, configuraciones eternas y capas de abstracción innecesarias. Mi enfoque es el contrario: construir herramientas funcionales, aplicaciones interactivas y lógica de optimización exprimiendo la potencia nativa de la web y el código directo.

---

### 🛠️ Lo que encontrarás aquí
* **One-File Apps / Standalone Labs:** Aplicaciones interactivas completas (WebGL, 3D, Canvas) autocontenidas en arquitecturas mínimas, listas para abrir y usar sin compiladores ni dependencias pesadas.
* **Herramientas para problemas reales:** Lógica aplicada a optimización operativa, herramientas de cálculo y utilidades directas al grano.
* **Zero-Overhead:** Si se puede resolver con matemáticas, APIs nativas del navegador y código limpio, sobra meter 20 librerías extra.
